## 🎯 Sobre o curso

Este repositório reúne os materiais, notas de aula e exemplos práticos utilizados no curso de **Planejamento Experimental e Análise de Dados**, voltado para estudantes e profissionais das ciências agrárias. O conteúdo é organizado em dois dias de aula, abrangendo desde os princípios básicos da experimentação até técnicas avançadas de comparações múltiplas com suporte do software GENES.

O curso foi pensado para quem deseja:

- Compreender os princípios fundamentais do delineamento experimental agrícola;
- Aplicar corretamente a análise de variância (ANOVA) e suas pressuposições;
- Escolher o teste de comparação de médias adequado ao seu experimento;
- Utilizar o software GENES como ferramenta de apoio às análises.

## 🚀 Como utilizar este material

1. **Acesse o site publicado:** [https://tiagobchagas.github.io/Curso_Genes/](https://tiagobchagas.github.io/Curso_Genes/)
2. **Navegue pelos dias do curso** usando o menu ou o índice.
3. **Baixe os arquivos** deste repositório para acompanhar as aulas:

```bash
# Clone o repositório
git clone https://github.com/tiagobchagas/Curso_Genes.git

# Acesse a pasta
cd Curso_Genes
```

4. **Abra o arquivo `index.html`** em seu navegador para visualizar o conteúdo localmente.

## 🤝 Contribuições

Contribuições são bem-vindas! Caso encontre erros, tenha sugestões ou queira acrescentar exemplos:

1. Faça um **fork** do projeto;
2. Crie uma **branch** para sua alteração:
   ```bash
   git checkout -b minha-contribuicao
   ```
3. **Commit** suas mudanças:
   ```bash

   ```

